Work breakdown and task traceability

The project contains 25 actual YouTrack issues, EDU-1 to EDU-25, created on 22 October 2026. The local planning IDs W01-W25 remain in the descriptions; project-management/issue-map.csv records the verified mapping and URLs. Each issue is assigned to the student’s admin account and includes its priority, expected outcome, acceptance criteria, dependency references and target. The admin account is owned by Ayan; it is not a separate project contributor. Prepared documents remain in review until their criteria, including required human evidence, are met.

The repository should have one permanent remote, a reviewed main branch and task branches. Include the real tracker ID in each branch and commit or pull-request description, and link the change back from the task. Significant design and evaluation changes need selected supervisor reviews at agreed checkpoints. Do not create fake historical commits or backdate work. A repository created on 22 October can honestly show work from that date; it cannot demonstrate earlier progressive development.
